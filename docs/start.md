# 快速上手

> English: see [README.en.md](https://github.com/xuanlv2002/ezharness/blob/main/README.en.md). 本页三步跑起来——原则只有一条：**exe 在哪运行，配置与数据就在哪生成**，零配置可用。

## 安装

从 [Releases](https://github.com/xuanlv2002/ezharness/releases) 下载，三种方式任选其一：

### 方式一：绿色版（免安装）

1. 下载 `ezharness-v<版本>.exe`（可改名 `ezharness.exe`），放入任意文件夹（如 `D:\ezharness`）；
2. 将该文件夹加入 PATH 环境变量；
3. 任意终端输入 `ezharness` 启动。首次运行在同目录自动生成 `ezharness.json` 与 `data\`。

### 方式二：安装包

1. 下载安装包并运行；
2. 按引导选择安装目录，自动创建开始菜单与桌面快捷方式，可选「添加到 PATH」。

### 方式三：纯 server 形态（无桌面壳）

直接运行 `ezharness-core.exe`，浏览器访问 `http://127.0.0.1:<port>`——与桌面端同一份页面；浏览器控制等桌面专属能力自动降级。启动日志会打印带令牌的访问地址。

## 配置模型

进入「模型」页，填入 apiKey 并选择模型。四个槽位各管一摊：

| 槽位 | 用途 |
|---|---|
| main | 主模型：驱动对话与工具调用（必填） |
| vision | 视觉：主模型无多模态时，读图走它 |
| image | 图片识别：独立识图能力 |
| audio | 音频：语音输入 |

每槽单选启用，附带用量统计。改完即生效（进程内重建 agent，无需重启）。

## 第一轮对话

1. 回到对话页，直接把任务交给它——文件整理、脚本编写、报错排查、网页操作都行；
2. agent 需要你时（审批 / 提问），决策卡会出现在时间线与右上角通知栏，点一下就回；
3. 随时可以：
   - 拉开工作区抽屉看它的**终端**，接管或纠错——你敲的命令它下一轮就知道；
   - 让它**操作网页**，浏览器窗口弹出共见，你随时原生接管；
   - 对任意消息点**分叉**，换个方案并行试；长对话点**归档**，沉淀记忆开新篇。

## 常见问题

**端口被占用？** 设置页把端口/监听地址改掉，点「应用并重启」即换代生效（进程内完成）。

**数据在哪？** exe 同目录的 `data\`（可在设置页改到别的盘）。会话、记忆、技能、快应用全在里面，整体拷走即搬家。

**外部工具想调 API？** 全部 `/api/*` 需要令牌：设置页「服务端配置」里有 API 访问令牌，可一键复制；请求带 `X-EZ-Token` 头或 `?token=` 即可（本机页面同源免令牌）。

**网页版能用吗？** 能。浏览器访问同一份页面，只有浏览器控制等桌面专属能力降级。
