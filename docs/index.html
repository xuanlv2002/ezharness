Desktop agent harness

不是聊天框，是一张可持续进化的工作台。

对话只是入口。文件、终端、浏览器在同一张台面上，每一步都摊开给你看；每次交付的成果沉成快应用——能打开、能复用，也能被下一次对话里的 agent 自己找回来。

ezharness
功能

真正的工作，发生在对话之外

文件系统、终端、浏览器都是真的：你和 AI 共用同一套环境。每次交付的成果也留在台面上，而不是散在聊天记录里。

树状会话

任意消息分叉，长对话归档沉淀。并行探索，切线不打断后台任务。

共享终端

人和 agent 写同一个真实 shell，命令互相可见，随时接管。

共享浏览器

内嵌真实 Chromium，AI 操作的就是你眼前这个页面。

快应用

AI 交付的不是代码块，是能被打开、复用、再次调用的应用。

会话

对话是一棵树，不是一条时间线

线性聊天记录是机器日志，不是人思考的形状。任何一条消息都能分叉出新的可能，长对话归档为记忆后换代，一条都不丢。

  • 分叉：复制完整前缀，新线独立运行。
  • 归档：沉淀记忆，生成交接摘要，旧世代可回读。
  • 并行：切换分支不影响后台正在跑的任务。

协同

你和 AI 共用同一个终端、同一个浏览器

不是「AI 做完再给你看」。终端里它敲的命令你随时能接；浏览器里你直接点页面就是接管，不需要先让它停手。

  • 可见：每一步操作都在时间线里。
  • 可接管：原生页面、同一个 PTY，没有模拟层。
  • 可追责：四档审批，决定权留在人手里。

交付

快应用：AI 产出一个能再次调用的应用

一个目录、一份 app.quick、一份调用文档，就是一个软件单元。协议只约定它如何被发现、启动和描述自己，不绑技术栈，不写死调用方式。

  • 目录即身份，未识别字段忽略，协议向前兼容。
  • 能否被调用，只看 APP.md 有没有「Agent 调用」一节。
  • 同源运行，可直接使用 MCP 与模型能力。
  • 固化流程，把反复出现的 MCP 调用写成代码，执行不再经过 agent 循环。
